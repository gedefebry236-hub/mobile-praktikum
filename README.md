# Proyek Pemrograman Mobile

## Tujuan
Aplikasi mobile berbasis Flutter yang dirancang untuk memudahkan pengguna dalam melakukan pengelolaan transaksi keuangan digital secara praktis dan efisien.

## Rencana Fitur
1. **Scan QRIS**: Mempercepat proses pembayaran langsung di kasir toko atau tempat usaha.
2. **DANA Emas**: Memberikan kemudahan menabung atau berinvestasi emas dalam nominal kecil.
3. **Kirim Uang (Transfer)**: Mempermudah pengiriman saldo antarbank secara aman.

## Cara Menjalankan
Pastikan perangkat atau emulator sudah terhubung, kemudian jalankan perintah berikut di terminal:
```bash
flutter pub get
flutter run
